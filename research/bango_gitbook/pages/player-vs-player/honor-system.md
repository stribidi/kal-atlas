# Honor System

## Honor Points

The points provide honor rank progression. Each player versus player activity grants points for participation, but also for additional conditions such as winning or specific achievements.

Honor points define player honor rank. Specific high-grade ranks are limited per server. For example there can only be one General rank:

| Rank       | Required Honor Point | Max Per Server |
| ---------- | -------------------- | -------------- |
| General    | 111600               | 1              |
| Colonel    | 78740                | 9              |
| Major      | 57970                | 25             |
| Captain    | 44640                | 49             |
| Lieutenant | 35030                | 81             |
| Sergeant   | 20150                | N/A            |
| Corporal   | 12090                | N/A            |
| Specialist | 7750                 | N/A            |
| Private    | 4960                 | N/A            |
| Recruit    | 2790                 | N/A            |

Ranks limited by amount update automatically after ever server restart.

Honor ranks increase amount of free daily E-Mok time. Please refer to [E-Mok explaination](/kalonline-2012-content/areas/e-mok-island.md) page.

## Reward Points

The points is a currency which is used by multiple merchants around the world.
